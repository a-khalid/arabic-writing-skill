# الاختبارات

ملف [`cases.json`](cases.json) يضم حالات لقياس جودة المهارة.

## طريقة التقييم
1. شغّل كل حالة مرتين: **مع المهارة** و**بدونها**.
2. لكل حالة:
   - `must_fix`: يجب أن يظهر كل تصحيح منها في المخرج.
   - `must_keep`: يجب أن يبقى النص كما هو دون تغيير.
   - `must_suggest_not_error`: يجب أن يُعرض بنوع «الأفصح» لا «خطأ».
   - `expect`: معايير يحكم عليها مراجع بشري أو نموذج آخر.
3. احسب نسبة النجاح، وقارن بين التشغيلين.

## إضافة حالة
أضف حالة جديدة لكل خطأ تكتشف أن المهارة تقع فيه، ثم عدّل المرجع المناسب حتى تنجح الحالة.
