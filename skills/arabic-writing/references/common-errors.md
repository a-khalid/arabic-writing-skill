# الأخطاء الشائعة والعبارات المترجمة

العمود «الحكم» مهم:
- **خطأ**: يُصحَّح دائمًا.
- **الأفصح**: الاستعمال الأول أجازته المجامع اللغوية أو بعض اللغويين، فيُقترح البديل ولا يُعدّ خطأً.

## ١. أخطاء في المفردات والتراكيب

| الشائع | الصواب / الأفصح | الحكم | السبب |
|---|---|---|---|
| انشاء الله | إن شاء الله | خطأ | إملاء؛ «إنشاء» مصدر |
| لا زال (للاستمرار) | ما زال | خطأ | «لا زال» للدعاء: لا زال بيتك عامرًا |
| سوف لن | لن | خطأ | «سوف» للإثبات، ولا تدخل على النفي |
| الغير مسؤول | غير المسؤول | الأفصح | «غير» لا تُعرَّف بأل في الأفصح |
| بالرغم من | على الرغم من | الأفصح | «على الرغم» هي الواردة عن العرب |
| نفس الشيء | الشيء نفسه | الأفصح | التوكيد يأتي بعد المؤكَّد |
| كافة الموظفين | الموظفون كافةً | الأفصح | «كافة» تُستعمل حالًا منصوبة |
| ساهم في | أسهم في | الأفصح | «ساهم» قارع بالسهام؛ وأجازها مجمع القاهرة |
| هامّ | مهمّ | الأفصح | «هامّ» من الهمّ أي المُقلق؛ وأجازها المجمع |
| تفاجأ | فوجئ | الأفصح | الفعل «فاجأ» متعدٍّ، ومطاوعه «فوجئ» |
| تواجد (بمعنى وُجد) | وُجد، حضر | الأفصح | «التواجد» إظهار الوجد |
| أخصائي | اختصاصي | الأفصح | النسبة إلى «اختصاص» |
| مبروك | مبارك | الأفصح | «مبروك» من برك البعير |
| يتوجّب | يجب | الأفصح | |
| عدم التمكن من | العجز عن، تعذّر | أسلوب | إيجاز |
| كلما ... كلما | كلما ... (مرة واحدة) | خطأ | كلما اجتهدت نجحت |
| بين ... وبين (اسمين ظاهرين) | بين ... و... | الأفصح | تكرار «بين» يكون مع الضمير: بيني وبينك |
| هل ... أم | هل ... أو / أ... أم | خطأ | «أم» تعادل الهمزة لا «هل» |
| يجب أن لا | يجب ألّا | إملاء | تُدغم «أنْ» في «لا» |

## ٢. أساليب مترجمة (عُجمة التركيب)

| المترجم | البديل العربي | ملاحظة |
|---|---|---|
| تمّ افتتاح المعرض | افتُتح المعرض | استعمل المبني للمجهول مباشرة |
| تمّ عقد الاجتماع من قبل الإدارة | عقدت الإدارة الاجتماع | لا حاجة لـ«من قبل» مع الفاعل المعروف |
| قام بزيارة المصنع | زار المصنع | الفعل المباشر أوجز |
| قام بتوقيع العقد | وقّع العقد | |
| أنا كمدير أرى | أرى بصفتي مديرًا | الكاف للتشبيه |
| لعب دورًا كبيرًا | أدّى دورًا كبيرًا، أسهم إسهامًا كبيرًا | |
| على أية حال | على كل حال، مهما يكن | |
| يتكون من | يتألف من، يتركب من | «يتكون» مقبولة؛ نوّع |
| أخذ بعين الاعتبار | راعى، وضع في الحسبان | |
| بالتالي | لذلك، ومن ثَمّ، فـ | «بالتالي» مقبولة؛ نوّع الروابط |
| في الوقت الذي | بينما، في حين أنّ | |
| مما لا شك فيه أن | لا شك أن | إيجاز |
| يعتبر من أهم | يُعدّ من أهم | «اعتبر» أصلها الاتعاظ، وأجازها المجمع بمعنى عدّ |
| الأكثر أهمية | الأهم | صيغة التفضيل المباشرة |
| ليس فقط ... بل أيضًا | لا ... فحسب، بل | ليس ... فحسب، بل ... كذلك |
